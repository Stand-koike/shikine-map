# 外浦マップ

Google スプレッドシートの店舗データを、イラスト地図上に表示する Web アプリです。

**公開 URL（例）:** `https://stand-koike.github.io/sotoura-map/`

---

## 主な機能

- イラスト地図上の店舗ピン表示
- カテゴリ・タグでの絞り込み
- 日本語 / 英語の切り替え
- LINE 投稿のかわら版表示（設定時）

---

## データの更新

店舗情報は Google スプレッドシートで管理します。シートを更新すると、マップにも反映されます（自動更新の間隔は数秒〜数十秒です）。
