# 敷根フェスマップ — 機能・UI のやりたいことリスト

**このファイルとチャットの両方で整理して問題ありません。**  
モバイルからは、Cursor のチャットに箇条書きで送る → Agent がここに反映、が一番楽です。  
PC で直接編集しても構いません。

---

## 書き方（コピペ用）

```
### [短い名前]
- 目的: （誰が何を楽にするか）
- 画面: マップ / 下カード / 詳細モーダル / フィルタ / その他
- 優先度: 必須 / あったら良い / 後回し
- メモ: （参考 URL・外浦マップとの差分など）
```

---

## 状態の意味

| 状態 | 意味 |
|------|------|
| 💡 idea | 要望だけ。未着手 |
| 📋 spec | 仕様を文章化済み |
| 🔧 dev | 実装中（PR 番号を書く） |
| ✅ done | 本番 or main に入った |
| ❌ cut | フェスではやらない |

---

## やりたいこと（ここに追記）

### 例: ブースをカテゴリで絞り込み

- 目的: 来場者が「グルメだけ」見たい
- 画面: フィルタ・下カード
- 優先度: 必須（※外浦マップと同機能なら既に実装済みの可能性あり）
- 状態: 💡 idea
- メモ: 既存 UI で足りるか要確認

---

## 敷根フェス向けの確認メモ（Agent 用）

| 領域 | 現状（main） | 要相談 |
|------|----------------|--------|
| LINE かわら版 | `ENABLE_LIVE_POSTS: false` | フェス中の告知はシート `news` 列のみで足りるか |
| 固定ピン（トイレ等） | `FIXED_MASTER_SHEET: null` | トイレ・救護・ゴミ捨て場を載せるか |
| 英語 | 切替 UI あり | ブース名の英語列をどこまで埋めるか |
| ディープリンク `?spot=` | 実装済み | SNS 用に store_id 命名ルール |
| GA4 | `GA_MEASUREMENT_ID` 空 | 測定 ID があれば設定 |

---

## チャットに送るときのヒント

- **スクショ**や **外浦マップの「ここと同じに」** はそのまま送って OK
- 「モバイルだけ」「iPhone Safari だけ」など **端末** を書いてもらえると助かります
- 締切（例: フェス 2 週間前）があれば一緒に書いてください
