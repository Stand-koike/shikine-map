## ボトムナビ（方針）

| ボタン | 動き |
|--------|------|
| **探す** | カテゴリで **ピンを消さない**。対象を大きく／非対象を小さく薄く |
| **タイムテーブル** | 下からシート。**半分（マップと同居）** と **全面**。行タップで対応ピンへ |
| **3つ目** | 未定。仮で **公園**（フェス概要・電話）。下の案から選んでください |

### 3つ目ボタンの案

1. **公園**（仮実装）— 日時・入場無料・問い合わせ電話。迷ったときの「総合案内」
2. **いま** — 現在時刻に近いプログラムだけ出す（タイムテーブルの短縮版）
3. **トイレ** — 3箇所が揃ったらワンタップでトイレだけ強調
4. **注意** — 雨天中止・小学生付添・おむつ不可など注意書きまとめ

レイヤー ON/OFF（ピン非表示）はフェスでは使わない想定です。
