# 敷根公園フェスマップ — ファイル構成

このフォルダが GitHub Pages の公開対象です。

| ファイル | 説明 |
|----------|------|
| `index.html` | マップアプリ本体 |
| `config.js` | 地図・表示の設定 |
| `line-contract.js` | データ形式の定義 |
| `map.webp` | イラスト地図画像 |
| `secrets.example.js` | 設定サンプル（実際の値は Git に含めない） |
| `wordpress-kawara-widget.js` | WordPress 埋め込み用ウィジェット |
| `assets/fixed-pins/` | 固定施設ピンのアイコン画像 |
