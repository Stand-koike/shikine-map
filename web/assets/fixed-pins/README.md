# 固定施設ピン画像（敷根フェス・総合運動公園）

固定マスタの `category` と `config.js` の `FIXED_PIN_ICONS` で紐付けます。  
**未配置の PNG はコミットしません**（決まったファイルだけ追加）。

## リポジトリに含まれるもの（外浦由来）

| ファイル | category 例 | 敷根での用途 |
|----------|-------------|--------------|
| `toilet.png` | `toilet` | トイレ ×3 |

## 敷根フェスで用意が必要（ファイル名・デザイン未決）

| 用途 | 件数 | category（案） | 状態 |
|------|------|----------------|------|
| パフォーマンスステージ | 1 | `stage` | PNG 未決 |
| 子供プレイエリア | 1 | `kids_play` | PNG 未決 |
| 屋内 WS | 2 | `ws_indoor` | PNG 未決 |

詳細: [docs/PIN_INVENTORY_SHIKINE.md](../../docs/PIN_INVENTORY_SHIKINE.md)

## その他（今回未使用）

`parking.png` / `viewspot.png` / `busstop.png` 等は外浦用。敷根で使う場合は category を設計に追加。

画像がない場合、マップ上は絵文字フォールバックになります（本番では PNG 配置を推奨）。
