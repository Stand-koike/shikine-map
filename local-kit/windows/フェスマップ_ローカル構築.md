## 1. 初回セットアップ（10分）

### 必要なもの

| ソフト | 用途 |
|--------|------|
| [Git for Windows](https://git-scm.com/download/win) | リポジトリ取得 |
| [Node.js LTS](https://nodejs.org/) | ローカル Web サーバ（`npx serve`） |
| [QGIS](https://qgis.org/) | イラストの地理参照・点の確認 |
| （任意）[OSGeo4W](https://trac.osgeo.org/osgeo4w/) | GeoTIFF → WebP・四隅の自動読み取り |

### 手順

1. PowerShell を開く。
2. リポジトリを作業ルートにクローン（未クローンの場合）:

```powershell
$Base = "C:\Users\vagab\Desktop\Stand\01.案件\フェスマップ"
New-Item -ItemType Directory -Force -Path $Base | Out-Null
Set-Location $Base
git clone https://github.com/Stand-koike/shikine-map.git
```

3. フォルダ一式を作成し、秘密設定のひな形を置く:

```powershell
Set-Location "$Base\shikine-map"
powershell -ExecutionPolicy Bypass -File .\local-kit\windows\Setup-LocalFesMap.ps1 -BasePath $Base
```

4. `web\secrets.local.js` を編集（`secrets.local.js.template` をコピー済み）:

   - `MAPBOX_TOKEN` … Mapbox の `pk.*`
   - `SHEET_ID` … スプレッドシート ID

5. マップを起動:

```powershell
powershell -ExecutionPolicy Bypass -File "$Base\shikine-map\local-kit\windows\Start-Map.ps1" -BasePath $Base
```

ブラウザで表示された URL（例: `http://localhost:3000`）を開く。

## 2. フォルダ構成（整理後）

```
フェスマップ\
├── shikine-map\              … Git リポジトリ（コード本体）
│   └── web\                  … マップアプリ（serve はここ）
├── qgis\
│   ├── source\               … QGIS 用の元データ（手元のファイルをここへ）
│   │   ├── 0park.png         … イラスト（ファイル名は何でも可）
│   │   ├── 0park.png.points  … Georeferencer の GCP
│   │   ├── 4point.csv
│   │   └── point.csv
│   └── export\               … QGIS から書き出した成果物
│       └── park_4326.tif     … 下記手順で作成（最重要）
├── secrets\                  … バックアップ用（本番は web\secrets.local.js）
└── README_ローカル.txt       … この説明へのショートカット
```

**ルール**

- **Git に入れるもの**: `web/` 内のコード・`map.webp`・`data/*.geojson`・`docs/sheets/*.csv` など（秘密は除く）
- **Git に入れないもの**: `secrets.local.js`、`config.local.js`、`qgis/export/*.tif`（大きい場合）

## 3. QGIS で「確実に合わせる」書き出し（GeoTIFF）

チャットに貼らず、**ローカルの `qgis\export\` に保存**してください。

1. QGIS で、**紫の点がイラストに乗っている状態**のプロジェクトを開く。
2. 地理参照済みの **イラストレイヤー**を右クリック → **エクスポート** → **名前を付けて保存**。
3. 設定:
   - 形式: **GeoTIFF**（`.tif`）
   - CRS: **EPSG:4326 - WGS 84**
   - 範囲: **レイヤの範囲**（マップキャンバス全体ではない）
4. 保存先:  
   `C:\Users\vagab\Desktop\Stand\01.案件\フェスマップ\qgis\export\park_4326.tif`

5. 同じプロジェクトから点レイヤーがある場合:  
   **ベクタ** → **名前を付けて保存** → `point_wgs84.geojson`（CRS: EPSG:4326）を `qgis\export\` に。

### Web 用に反映（GDAL あり）

OSGeo4W の `gdalinfo` が PATH にある状態で:

```powershell
powershell -ExecutionPolicy Bypass -File "$Base\shikine-map\local-kit\windows\tools\Import-GeoTiff.ps1" `
  -GeoTiff "$Base\qgis\export\park_4326.tif" `
  -WebRoot "$Base\shikine-map\web"
```

- `web\map-qgis.webp` と `web\config.local.js`（四隅・画像 URL）が生成されます。
- `Start-Map.ps1` で再起動し、**QGIS と同じ見え方**か確認。

GDAL が無い場合は、`qgis\export\README_GDALなし.md` の手動手順（四隅を `gdalinfo` 相当で QGIS から読む）を使います。

## 6. 困ったとき

| 症状 | 確認 |
|------|------|
| 真っ青でイラストが見えない | `config.local.js` をいったん削除し、`map.webp` のみで表示 |
| 点だけずれる | 点とイラストが **同じ QGIS プロジェクト**から出ているか |
| トークン未設定 | `web\secrets.local.js` の場所と `MAPBOX_TOKEN` |

質問するときは **「QGIS のスクショ」＋ `qgis\export` に tif があるか」** だけ教えてもらえれば次の一手を固定できます。
